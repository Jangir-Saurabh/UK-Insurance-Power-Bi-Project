# 📊 UK Insurance Claims Analysis — Power BI

An interactive Power BI dashboard designed to analyze and visualize UK insurance claims data and uncover meaningful business insights.

## 🔍 Project Overview

This project provides a comprehensive analysis of insurance customers, policies, claims, claim categories, approval rates, financial amounts, geographical performance, and settlement times.

## 📌 Key Analysis

- 👥 Customer & Gender Analysis
- 📋 Policy Analysis
- 🧾 Claims Analysis
- 🏷️ Insurance / Claim Type Analysis
- 💰 Requested & Paid Claim Amount
- ✅ Claim Approval Rate
- 🌍 Region & Nation Analysis
- ⏱️ Average Claim Settlement Time
- 📈 High-Claim Customer Analysis
- 🔎 Policy-Level Claim Analysis
- 📊 Region-wise Approval Analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization

## 🎯 Objective

The objective of this project is to transform raw insurance data into an interactive analytical dashboard that helps understand customer behavior, claim patterns, policy performance, financial outcomes, and geographical trends.

## 📂 Project Contents

- Power BI Dashboard
- Dataset
- DAX Measures
- Data Model
- Dashboard Background / Visual Assets
- Project Documentation

## 📊 Dashboard

The dashboard presents key KPIs and interactive visualizations to make insurance claim data easier to understand and analyze.
